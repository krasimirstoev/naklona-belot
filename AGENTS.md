# Проверки според промяната

Тези правила важат за целия проект.

- Избирай най-малката проверка, която дава увереност за засегнатото поведение.
- За текстови, стилови и други малки, обратими промени не добавяй автоматично тестове.
- За промени в логиката изпълнявай съответните тестове; добавяй нови при ново поведение или поправен бъг, когато дават полезна защита.
- Пускай целия тестов набор (`npm test`), build (`npm run build`) или Playwright (`npm run test:e2e`) при широко засягане, интеграционен риск или конкретно съмнение.
- След успешна проверка не я повтаряй без нова промяна или причина.
- В края посочвай накратко какво е проверено.
