# Medium при текущите правила — 23 октомври 2026

Сравнение със замразения стар Medium от `benchmarks/no-trump-baseline`.
И двата отбора играят през текущия двигател. Политиките не са променяни или
настройвани за измерването. Използвани са същите семена и разменени отбори
като в [предишното измерване](current-medium.md).

Правила: бягане от контра изключено; анонсите и белотът не се умножават;
по-високото каре печели; валатът отменя контрата и реконтрата. Печелившият
отбор запазва всички свои поредици. Задължителното качване се прилага от
двигателя. Разкриването на анонсите и поясненията за качване не променят
вече съществуващото сравняване на поредиците или допустимите ходове.

## Цели мачове с реално наддаване

512 независими семена × два разменени отбора = 1024 завършени мача.

| Показател | Преди | Сега |
| --- | ---: | ---: |
| Победи на текущия Medium | 492 / 1024 | 490 / 1024 |
| Процент победи | 48,05% | 47,85% |
| 95% интервал за процента | 45,41–50,68% | 45,21–50,49% |
| Медиана на крайната разлика в точки | −6,5 | −7 |
| Средна крайна разлика в точки | −1,03 | −1,07 |
| Завършени раздавания | 13 409 | 13 405 |
| Раздавания с четири паса | 1434 | 1436 |

Разликата е −0,20 процентни пункта: два мача сменят победителя от текущия
към стария Medium. Резултатът не доказва преимущество на текущия Medium.
Доверителният интервал допуска и малко предимство, и изоставане спрямо 50%.
Медианата на дължината е 13 раздавания на мач.

В естествено избраните козови договори текущият отбор изпълнява 769 от 823
(93,44%). Това са подбрани от наддаването ръце, а не контролирана оценка на
силата. Не бива да се сравнява с процента спечелени цели мачове.

В наддаването има 19 контри и 2 реконтри. Правилата за контра засягат малка
част от тази естествена извадка; функционалните тестове покриват изрично
граничните случаи. Няма основание резултатите да се обобщават за човешки
опоненти или други версии на ботовете.

[Суров отчет за мачовете](current-medium-new-rules-matches.json) съдържа
всички резултати, правилата, хешове на източниците и медианите. Проверени са
броят победи, разменените отбори за всяко семе, сборовете на точките,
раздаванията, четирите паса и достигането на 151.

## Команди и проверки

```sh
npm test
npm run build
npm run test:e2e
npm run test:training
node --import tsx scripts/bot-match-benchmark.ts --seeds 512 --seed-start 6000001 --progress --output docs/benchmarks/current-medium-new-rules-matches.json
npm run train:bots -- --a medium --b medium-nt-before --seeds 1024 --seed-start 5000001 --split heldout --output docs/benchmarks/current-medium-new-rules-all-contracts.json
```

Успешни: 110 Node теста, 26 Python теста, production build и 34 браузърни
теста. Две браузърни проверки се пропускат по конфигурация: пълен мач на
телефон и матрица от телефонни размери на desktop. Допълнително минаха
TypeScript проверката на benchmark-а и `git diff --check`.

Мачовият benchmark отне около 254 секунди. Измерванията вървяха паралелно
с други проверки, затова времената на отделните решения не са контролирано
сравнение на производителността.
